Subresource integrity là cơ chế cho phép browser kiểm tra file JavaScript tải về có đúng nội dung mà application mong đợi hay không. Document cung cấp một cryptographic hash cho resource. Browser tải file, tính hash từ nội dung thật rồi so sánh. Nếu hai giá trị khớp, resource được sử dụng. Nếu không khớp, browser chặn script. Hash không mã hóa và không che giấu code. Nó chỉ tạo fingerprint của exact content. Một thay đổi rất nhỏ như thêm khoảng trắng, đổi newline hoặc minify bằng cấu hình khác cũng có thể tạo hash mới. Vì vậy subresource integrity là cơ chế fail closed. Khi phát hiện mismatch, browser ưu tiên an toàn và từ chối script. Trên payment page, hành vi này có thể làm payment method hoặc place order ngừng hoạt động, nhưng việc chặn là đúng theo security design. Root cause cần được sửa trong build và deployment, không nên bỏ thuộc tính integrity chỉ để page chạy lại. Tư duy chính là xem JavaScript và hash tương ứng như một artifact không thể tách rời. Nếu html, file và hash đến từ ba trạng thái khác nhau, validation không thể đáng tin cậy.
